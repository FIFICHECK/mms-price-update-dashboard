❓ 使用說明

基本流程：新增 SKU → 加入促銷階段（每階段：執行時間 + 原價/售價 + 折扣文字 + 格式）→ 系統 cron（每 15 分鐘）到期自動登入 MMS 更新。

多階段：一個 SKU 可以有多個階段（例如 朝早 85 折 → 夜晚 7 折），各自設定時間，到期逐個執行，列表同時顯示進度（如 1/2）。

促銷 + 自動還原：每個階段可填「完結時間」+「完結後售價」— 系統有兩類動作：
  💰 促銷（執行時間到）→ 改原價/售價/折扣文字
  🔄 還原（完結時間到）→ 自動將售價改返「完結後售價」（例如促銷完還原 $368）

改價記錄：每次執行會記錄「改前 → 改後」價格（例如 $368 → $358），喺「📝 更新記錄」頁面睇到。

欄位說明：

  • SKU ID：完整格式 商店ID_S_SKUID，例如 B0961005_S_4891133140895_24；列表/記錄中嘅 SKU 連結會帶埋前綴
  • 執行時間：幾時改價（促銷開始）
  • 完結時間：促銷期完結（可選）
  • 售價 = 0：取消促銷
  • 完結後售價：完結時間到後自動改返呢個價（可選）
  • 折扣文字格式：Style 1 紅 / Style 2 灰刪除線 / Style 3 黑 / Style 4 藍，可多選；若 MMS 鎖死（disabled）會自動偵測，一致就當 OK
  • 監察時段：自動 = 第一階段執行開始 → 最後階段完結時間，唔使手動填

頂部卡片：

  • 🔄 Next Check：cron 下次檢查倒數（每 15 分鐘邊界），Hover 睇實際時間
  • 🔄 Auto Refresh：頁面自動刷新倒數（每 2 分鐘），Hover 睇實際時間
  • 🔄 刷新按鈕：手動即時刷新（唔跟 Next Check / Auto Refresh）

狀態說明：

  • 待執行 未開始
  • 執行中 部分階段已完成
  • 已完成 全部階段完成（含還原）
  • 失敗 更新失敗（檢查 MMS 登入/SKU 是否存在）

價格監察：每小時自動 check MMS 上執行中/已完成 SKU 嘅實際價（監察時段內），如有變會通知。
