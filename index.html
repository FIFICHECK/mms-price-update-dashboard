❓ 使用說明

基本流程：新增 SKU → 填促銷資料（原價/售價/折扣文字/格式）→ 設定執行時間 → 系統 cron（每 15 分鐘）到期自動登入 MMS 更新。

欄位說明：

  • SKU ID：完整格式 商店ID_S_SKUID，例如 B0961005_S_4891133140895_24
  • 售價 = 0：取消促銷
  • 折扣文字格式：Style 1 紅 / Style 2 灰刪除線 / Style 3 黑 / Style 4 藍，可多選

狀態說明：

  • 待執行 已設定，等待執行時間
  • 執行中/成功 已更新
  • 失敗 更新失敗（檢查 MMS 登入/SKU 是否存在）
  • 已完成 完成

注意：MMS session 有時會過期；失敗會自動記錄原因。資料儲存於 GitHub repo 嘅 config.json。
