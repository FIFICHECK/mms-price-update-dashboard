❓ 使用說明

基本流程：新增 SKU → 加入促銷階段（每階段：執行時間 + 原價/售價 + 折扣文字 + 格式）→ 系統 cron（每 15 分鐘）到期自動登入 MMS 更新。

多階段：一個 SKU 可以有多個階段（例如 朝早 85 折 → 夜晚 7 折），各自設定時間，到期逐個執行，列表同時顯示。

欄位說明：

  • SKU ID：完整格式 商店ID_S_SKUID，例如 B0961005_S_4891133140895_24
  • 售價 = 0：取消促銷
  • 折扣文字格式：Style 1 紅 / Style 2 灰刪除線 / Style 3 黑 / Style 4 藍，可多選
  • 監察時段：自動 = 第一階段執行開始 → 最後階段時間完結，唔使手動填

狀態說明：

  • 待執行 未開始
  • 執行中 部分階段已完成
  • 已完成 全部階段完成
  • 失敗 更新失敗（檢查 MMS 登入/SKU 是否存在）

價格監察：每小時自動 check MMS 上已完成 SKU 嘅實際價，如有變會通知。
